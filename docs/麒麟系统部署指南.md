# 麒麟系统 V10 部署 X 巡检平台

> 适用于银河麒麟 V10 操作系统

## 一、环境准备

### 1.1 检查系统环境

```bash
# 检查操作系统版本
cat /etc/kylin-release
# 输出类似: Kylin Linux Advanced Server V10 (Sword)

# 检查 Python 版本
python3 --version
# 输出类似: Python 3.7.9

# 检查网络连通性
ping -c 3 baidu.com
```

### 1.2 安装必要依赖

```bash
# 升级系统包
sudo yum update -y

# 安装 Python 编译工具（如果需要从源码编译）
sudo yum install -y gcc gcc-c++ python3-devel

# 安装 Git
sudo yum install -y git

# 验证安装
git --version
python3 --version
```

## 三、配置 Python 环境

### 3.1 创建虚拟环境

```bash
cd /opt/x

# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 升级 pip
pip install --upgrade pip

# 安装依赖
pip install -r requirements.txt

# 退出虚拟环境
deactivate
```

### 3.2 验证安装

```bash
source venv/bin/activate
python -c "import fastapi; print(f'FastAPI {fastapi.__version__}')"
python -c "import httpx; print(f'httpx {httpx.__version__}')"
pip list | grep -E "fastapi|uvicorn|httpx|pyyaml|jinja2"
deactivate
```

## 四、配置环境变量

### 4.1 复制配置示例

```bash
cd /opt/x
cp .env.example .env
```

### 4.2 编辑环境变量

```bash
nano .env
```

修改内容：
```bash

ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxx

# Elasticsearch 用户名密码（如需要）
ES_USERNAME=elastic
ES_PASSWORD=your_password

# 钉钉 webhook（如需要）

# 飞书 webhook（如需要）
FEISHU_WEBHOOK=https://open.feishu.cn/open-apis/bot/v2/hook/xxx
```

### 4.3 配置 Prometheus/ES 地址

```bash
nano config.yaml
```

确保以下配置正确：
```yaml
prometheus:
  url: http://your-prometheus-host:9090
  timeout_sec: 10

elasticsearch:
  url: http://your-elasticsearch-host:9200
  username: elastic  # 如需要
  password: your_password  # 如需要
```

## 五、配置定时任务（如需要）

### 5.1 编辑定时任务配置

```bash
nano config.yaml
```

在文件末尾添加：
```yaml
cron:
  jobs:
    - label: " daily-inspection"
      cron_expr: "0 1 * * *"  # 每天凌晨 1 点
      mode: "instant"
      skip_llm: false
      fmt: "html"
      notify:
        - type: "dingtalk"  # 或 "feishu"
        enabled: true
    - label: "weekly-report"
      cron_expr: "0 2 * * 0"  # 每周日凌晨 2 点
      mode: "instant"
      skip_llm: false
      fmt: "html"
```

## 七、配置 Systemd 服务（推荐）

### 7.1 创建服务文件

```bash
sudo nano /etc/systemd/system/x.service
```

内容：
```ini
[Unit]
Description=X巡检平台
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/x
ExecStart=/opt/x/venv/bin/python -m src.main web --host 0.0.0.0 --port 8000
Environment=PYTHONIOENCODING=utf-8
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

### 7.2 启用服务

```bash
# 重新加载 systemd
sudo systemctl daemon-reload

# 设置开机自启
sudo systemctl enable x

# 启动服务
sudo systemctl start x

# 查看状态
sudo systemctl status x

# 查看日志
sudo journalctl -u x -f
```

## 八、配置 Nginx 反向代理

### 8.1 安装 Nginx

```bash
sudo yum install -y nginx
```

### 8.2 创建配置文件

```bash
sudo nano /etc/nginx/conf.d/x.conf
```

内容：
```nginx
server {
    listen 80;
    server_name your-domain.com;  # 或服务器 IP

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket 支持
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # 超时设置
        proxy_connect_timeout 300s;
        proxy_read_timeout 300s;
    }
}
```

### 8.3 启用配置

```bash
# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx

# 设置开机自启
sudo systemctl enable nginx
```

### 8.4 配置 HTTPS（可选）

使用 Let's Encrypt 免费证书：
```bash
sudo yum install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

## 九、防火墙配置

### 9.1 开放端口

```bash
# 开放 8000 端口（应用）
sudo firewall-cmd --permanent --add-port=8000/tcp

# 开放 80 端口（HTTP）
sudo firewall-cmd --permanent --add-port=80/tcp

# 开放 443 端口（HTTPS）
sudo firewall-cmd --permanent --add-port=443/tcp

# 重新加载防火墙
sudo firewall-cmd --reload

# 查看开放端口
sudo firewall-cmd --list-ports
```

### 9.2 或者直接关闭防火墙（测试环境）

```bash
sudo systemctl stop firewalld
sudo systemctl disable firewalld
```

## 附录

### 常见问题

**Q: 启动报错 "No module named xxx"**
A: 虚拟环境中未安装对应包，执行 `pip install xxx`

**Q: 页面显示 500 错误**
A: 检��日志 `logs/sanssi.log`，常见配置错误或权限问题

**Q: 中文显示乱码**
A: 确保 `.env` 中 `PYTHONIOENCODING=utf-8`

**Q: Prometheus/ES 连接失败**
A: 检查 `config.yaml` 中的地址是否正确，防火墙是否放行
