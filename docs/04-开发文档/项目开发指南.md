# 项目开发指南

> 本指南面向开发人员，介绍X项目架构和开发要点

## 1. 项目结构

```
kzx/
├── src/                    # 源代码
│   ├── collectors/         # 数据采集
│   │   ├── prometheus.py   # Prometheus指标采集
│   │   └── elasticsearch.py # ES日志采集
│   ├── web/               # Web界面
│   │   ├── app.py          # FastAPI应用
│   │   ├── config_store.py # 配置管理
│   │   └── templates/      # 页面模板
│   ├── config.py           # 配置解析
│   ├── main.py             # CLI入口
│   ├── analyzer.py          # AI分析
│   └── reporter.py          # 报告生成
├── config.yaml             # 配置文件
├── docker-compose.yml       # 容器编排
├── templates/               # 报告模板
└── reports/                 # 生成的报告
```

### 2.2 应用层

**CLI命令 (src/main.py)**
```bash
python -m src.main inspect --skip-llm
```

**Web API (src/web/app.py)**
- GET / - 首页
- GET /sites - 机房配置
- GET /queries - 查询配置
- GET /settings - 系统设置
- GET /reports - 巡检报告
- POST /api/inspect - 触发巡检

## 3. 开发要点

### 3.1 添加新指标

在config.yaml中添加:
```yaml
prometheus:
  queries:
    - name: new_metric
      promql: 'new_metric_name'
      threshold: 100
      unit: ''
```

### 3.2 添加新日志类型

在config.yaml中添加:
```yaml
elasticsearch:
  queries:
    - name: new_log
      index: 'logstash-*'
      query_string: 'message:*new*'
      size: 50
```

### 3.3 添加新页面

1. 在templates/创建HTML
2. 在app.py添加路由
3. 配置render_template

## 4. 调试方法

### 4.1 本地调试

```bash
# 启动Web服务（热重载）
python -m src.main web --reload

# 运行CLI巡检
python -m src.main inspect --skip-llm --config config.yaml
```

### 4.2 Docker调试

```bash
# 进入容器
docker exec -it x-web /bin/sh

# 查看日志
docker logs -f x-web
```
