## 第一章：准备工作

### 1.1 需要的软件

| 软件 | 作用 | 下载地址 |
|------|------|----------|
| Docker Desktop | 容器管理 | docker.com |
| Git | 代码管理 | git-scm.com |
| VS Code | 文本编辑器 | code.visualstudio.com |

### 1.2 安装Docker (Windows)

1. 下载 Docker Desktop Installer.exe
2. 双击安装，全部选择"Next"
3. 安装完成后启动Docker

**验证：** 打开CMD，输入 `docker --version`

---

## 第二章：快速开始

### 2.1 下载项目

```cmd
git clone https://github.com/liuliu4356/kzx.git
cd kzx
```

### 2.2 启动服务

```cmd
docker-compose up -d
```

### 2.3 访问服务

| 服务 | 地址 |
|------|------|
| Grafana | http://localhost:3000 |
| Prometheus | http://localhost:9090 |
| 巡检Web | http://localhost:8000 |

---

## 第三章：使用巡检

### 3.1 Web界面操作

1. 打开 http://localhost:8000
2. 选择巡检模式（快照/24小时/7天）
3. 选择报告格式（HTML/Markdown）
4. 点击"🚀 开始巡检"
5. 等待完成后查看报告

### 3.2 命令行操作

```cmd
docker run --rm --network kzx_x_default -v %cd%:/app -w /app python:3.10-slim pip install -q -r requirements.txt && python -m src.main inspect --skip-llm
```

## 第四章：日常使用

### 4.1 启动服务
`docker-compose up -d`

### 4.2 停止服务
`docker-compose down`

### 4.3 查看日志
`docker-compose logs -f`

### 4.4 查看报告
在 `reports/` 文件夹中

---

## 第五章：常见问题

**Q: Docker启动失败**
A: 检查是否安装了WSL2，更新Windows到最新版本

**Q: 服务无法访问**
A: 检查防火墙设置，确保端口未被占用

**Q: 巡检报告为空**
A: 检查Prometheus是否有数据，查看Targets状态
