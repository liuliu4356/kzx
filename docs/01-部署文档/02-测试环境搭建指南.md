# 测试环境搭建指南

> 本指南介绍如何在测试环境快速搭建X项目监控系统

---

## 1. 环境要求

- 操作系统: Windows 10/11 或 Ubuntu 20.04+
- CPU: 4核心
- 内存: 8GB
- 硬盘: 100GB

---

## 2. 一键启动

### Windows

```cmd
# 1. 安装Docker Desktop
# 下载: https://www.docker.com/products/docker-desktop

# 2. 克隆项目
git clone https://github.com/liuliu4356/kzx.git
cd kzx

# 3. 启动服务
docker-compose up -d
```

### Linux

```bash
# 1. 安装Docker
curl -fsSL https://get.docker.com | sh

# 2. 克隆并启动
git clone https://github.com/liuliu4356/kzx.git
cd kzx
docker-compose up -d
```

---

## 3. 服务访问

| 服务 | 地址 | 用户名 | 密码 |
|------|------|--------|------|
| Grafana | http://localhost:3000 | admin | admin |
| Prometheus | http://localhost:9090 | - | - |
| Elasticsearch | http://localhost:9200 | - | - |
| 巡检Web | http://localhost:8000 | - | - |

---

## 4. 验证安装

```bash
# 检查服务状态
docker-compose ps

# 运行测试巡检
docker exec kzx python -m src.main inspect --skip-llm
```
