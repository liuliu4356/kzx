# 物理机安装指南（麒麟系统）

> 介绍在没有Docker的环境下如何在物理机部署X项目

---

## 1. Prometheus安装（物理机）

```bash
# 1. 下载（根据架构选择）
# x86_64:
wget https://github.com/prometheus/prometheus/releases/download/v2.51.0/prometheus-2.51.0.linux-amd64.tar.gz

# 鲲鹏(arm64):
wget https://github.com/prometheus/prometheus/releases/download/v2.51.0/prometheus-2.51.0.linux-arm64.tar.gz

# 2. 解压安装
tar xzf prometheus-2.51.0.linux-amd64.tar.gz
cd prometheus-2.51.0.linux-amd64

# 3. 创建目录
mkdir -p /data/prometheus /etc/prometheus

# 4. 复制配置
cp prometheus.yml /etc/prometheus/

# 5. 创建用户
useradd -r -s /sbin/nologin prometheus

# 6. 配置systemd
cat > /etc/systemd/system/prometheus.service << EOF
[Unit]
Description=Prometheus
After=network.target

[Service]
Type=simple
User=prometheus
ExecStart=/opt/prometheus/prometheus --config.file=/etc/prometheus/prometheus.yml --storage.tsdb.path=/data/prometheus
Restart=always

[Install]
WantedBy=multi-user.target
EOF

# 7. 启动
systemctl daemon-reload
systemctl enable prometheus
systemctl start prometheus
```

## 2. Node Exporter安装（物理机）

```bash
# 1. 下载
wget https://github.com/prometheus/node_exporter/releases/download/v1.7.0/node_exporter-1.7.0.linux-amd64.tar.gz

# 2. 安装
tar xzf node_exporter-1.7.0.linux-amd64.tar.gz
cp node_exporter-1.7.0.linux-amd64/node_exporter /usr/local/bin/

# 3. 创建systemd服务
cat > /etc/systemd/system/node-exporter.service << EOF
[Unit]
Description=Node Exporter
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/node_exporter
Restart=always

[Install]
WantedBy=multi-user.target
EOF

# 4. 启动
systemctl daemon-reload
systemctl enable node-exporter
systemctl start node-exporter
```

## 3. Elasticsearch安装（物理机）

```bash
# 1. 安装JDK（麒麟系统）
yum install -y java-11-openjdk

# 2. 下载ES
wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-8.13.0-linux-x86_64.tar.gz

# 3. 解压
tar xzf elasticsearch-8.13.0-linux-x86_64.tar.gz
mv elasticsearch-8.13.0 /opt/elasticsearch

# 4. 创建用户
useradd -r -s /sbin/nologin elasticsearch

# 5. 配置
cat > /opt/elasticsearch/config/elasticsearch.yml << EOF
cluster.name: x-monitor
node.name: node-1
path.data: /data/elasticsearch
network.host: 0.0.0.0
http.port: 9200
discovery.type: single-node
EOF

# 6. 启动
su - elasticsearch -c "/opt/elasticsearch/bin/elasticsearch -d"
```

## 4. Grafana安装（物理机）

```bash
# 安装
yum install -y https://dl.grafana.com/oss/release/grafana-10.3.0-1.x86_64.rpm

# 启动
systemctl enable grafana-server
systemctl start grafana-server

# 访问 http://localhost:3000
```

## 5. 巡检程序安装（物理机）

```bash
# 1. 安装Python 3.10+
python3 --version

# 2. 克隆项目
git clone https://github.com/liuliu4356/kzx.git

# 3. 安装依赖
pip3 install -r requirements.txt

# 4. 配置
cp config.example.yaml config.yaml
# 修改config.yaml中的URL为实际IP

# 5. 运行巡检
python3 -m src.main inspect --skip-llm
```
