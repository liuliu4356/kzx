# 物理机安装指南（无 Docker 环境）

> 本文档面向无法使用 Docker 的生产环境（如麒麟 V10、UOS 等信创操作系统），
> 介绍如何在物理机上手动安装三思GDB巡检平台及其依赖组件。

---

## 前言

三思GDB巡检平台依赖以下服务：

| 组件 | 版本要求 | 说明 |
|---|---|---|
| Python | ≥ 3.10 | 运行巡检主程序 |
| Prometheus | ≥ 2.40 | 指标存储与查询 |
| Node Exporter | ≥ 1.6 | 系统指标采集 |
| Elasticsearch | ≥ 7.x / 8.x | 日志存储与查询 |
| Grafana（可选） | ≥ 10.0 | 可视化面板 |

> **信创环境注意**：GoldenDB 生产环境通常已有 Prometheus + ES，巡检平台只需配置连接地址，
> 无需重复安装监控组件。跳至 [第 5 节](#5-巡检平台安装) 即可。

## 1. Prometheus 安装（物理机）

### 1.1 下载二进制包

```bash
# x86_64（Intel/AMD）
wget https://github.com/prometheus/prometheus/releases/download/v2.51.0/prometheus-2.51.0.linux-amd64.tar.gz

# aarch64（鲲鹏 ARM64 / 飞腾）
wget https://github.com/prometheus/prometheus/releases/download/v2.51.0/prometheus-2.51.0.linux-arm64.tar.gz
```

### 1.2 解压安装

```bash
tar xzf prometheus-2.51.0.linux-*.tar.gz
cd prometheus-2.51.0.linux-*

# 安装到 /opt
sudo cp prometheus promtool /usr/local/bin/
sudo mkdir -p /opt/prometheus /etc/prometheus /data/prometheus
sudo cp prometheus.yml /etc/prometheus/
sudo cp -r consoles/ console_libraries/ /etc/prometheus/
```

### 1.3 创建系统用户

```bash
sudo useradd -r -s /sbin/nologin prometheus
sudo chown -R prometheus:prometheus /data/prometheus /etc/prometheus
```

### 1.4 配置 systemd 服务

```bash
sudo tee /etc/systemd/system/prometheus.service << 'EOF'
[Unit]
Description=Prometheus Monitoring
After=network.target

[Service]
Type=simple
User=prometheus
ExecStart=/usr/local/bin/prometheus \
  --config.file=/etc/prometheus/prometheus.yml \
  --storage.tsdb.path=/data/prometheus \
  --storage.tsdb.retention.time=30d \
  --web.listen-address=0.0.0.0:9090
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable prometheus
sudo systemctl start prometheus
```

### 1.5 验证

```bash
curl http://localhost:9090/-/healthy
# → Prometheus Server is Healthy.
```

## 2. Node Exporter 安装

Node Exporter 部署在被监控的数据库节点上。

```bash
# x86_64
wget https://github.com/prometheus/node_exporter/releases/download/v1.8.0/node_exporter-1.8.0.linux-amd64.tar.gz

# aarch64
wget https://github.com/prometheus/node_exporter/releases/download/v1.8.0/node_exporter-1.8.0.linux-arm64.tar.gz

tar xzf node_exporter-1.8.0.linux-*.tar.gz
sudo cp node_exporter-1.8.0.linux-*/node_exporter /usr/local/bin/

sudo tee /etc/systemd/system/node-exporter.service << 'EOF'
[Unit]
Description=Node Exporter
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/node_exporter \
  --collector.diskstats \
  --collector.netdev \
  --collector.meminfo \
  --collector.cpu \
  --web.listen-address=:9100
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable node-exporter
sudo systemctl start node-exporter
```

验证：

```bash
curl http://localhost:9100/metrics | head -20
```

## 3. Elasticsearch 安装（物理机）

### 3.1 前置条件

```bash
# 安装 JDK 11（ES 8.x 内置 JDK，可跳过）
sudo yum install -y java-11-openjdk   # CentOS/麒麟
sudo apt install -y openjdk-11-jdk    # Debian/UOS

# 调整系统参数
sudo tee -a /etc/sysctl.conf << 'EOF'
vm.max_map_count=262144
EOF
sudo sysctl -p

# 调整文件描述符
echo "* soft nofile 65536" | sudo tee -a /etc/security/limits.conf
echo "* hard nofile 65536" | sudo tee -a /etc/security/limits.conf
```

### 3.2 下载安装

```bash
# x86_64
wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-8.13.0-linux-x86_64.tar.gz

# aarch64
wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-8.13.0-linux-aarch64.tar.gz

tar xzf elasticsearch-8.13.0-linux-*.tar.gz
sudo mv elasticsearch-8.13.0 /opt/elasticsearch
sudo useradd -r -s /sbin/nologin elasticsearch
sudo chown -R elasticsearch:elasticsearch /opt/elasticsearch
sudo mkdir -p /data/elasticsearch
sudo chown elasticsearch:elasticsearch /data/elasticsearch
```

### 3.3 配置

```bash
sudo tee /opt/elasticsearch/config/elasticsearch.yml << 'EOF'
cluster.name: gdb-monitor
node.name: node-1
path.data: /data/elasticsearch
path.logs: /var/log/elasticsearch
network.host: 0.0.0.0
http.port: 9200
discovery.type: single-node
xpack.security.enabled: false
EOF
```

### 3.4 配置 systemd 服务

```bash
sudo tee /etc/systemd/system/elasticsearch.service << 'EOF'
[Unit]
Description=Elasticsearch
After=network.target

[Service]
Type=simple
User=elasticsearch
ExecStart=/opt/elasticsearch/bin/elasticsearch
Restart=always
RestartSec=10
LimitNOFILE=65536
LimitMEMLOCK=infinity

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable elasticsearch
sudo systemctl start elasticsearch
```

验证（启动需等待约 30 秒）：

```bash
curl http://localhost:9200
# 返回 JSON，包含 "tagline": "You Know, for Search"
```

## 4. Grafana 安装（可选）

Grafana 仅用于可视化，巡检平台本身不依赖它。

```bash
# CentOS / 麒麟（x86）
sudo yum install -y https://dl.grafana.com/oss/release/grafana-10.3.0-1.x86_64.rpm

# CentOS / 麒麟（aarch64）
sudo yum install -y https://dl.grafana.com/oss/release/grafana-10.3.0-1.aarch64.rpm

sudo systemctl enable grafana-server
sudo systemctl start grafana-server
```

访问 http://服务器IP:3000，默认账号 admin / admin。

## 5. 巡检平台安装

### 5.1 安装 Python 3.10+

```bash
# 检查现有版本
python3 --version

# 麒麟 V10 通常内置 Python 3.9，需升级：
sudo yum install -y python310 python310-pip   # 若有官方源
# 或从源码编译（见麒麟系统部署手册附录）
```

### 5.2 克隆项目

```bash
git clone https://github.com/liuliu4356/kzx.git
cd kzx

# 或下载压缩包（无 Git 环境）：
wget https://github.com/liuliu4356/kzx/archive/refs/heads/master.zip
unzip master.zip && cd kzx-master
```

### 5.3 创建虚拟环境并安装依赖

```bash
python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
# 国内网络加速：
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

### 5.4 初始化配置

```bash
cp config.example.yaml config.yaml
```

最小化修改（替换为实际 IP）：

```yaml
prometheus:
  url: "http://10.x.x.x:9090"

elasticsearch:
  url: "http://10.x.x.x:9200"

llm:
  api_key_env: ANTHROPIC_API_KEY   # 或设置环境变量
```

设置 API Key 环境变量：

```bash
export ANTHROPIC_API_KEY="sk-ant-xxxx"
# 或写入 ~/.bashrc / /etc/profile.d/gdb-inspect.sh
```

### 5.5 验证安装

```bash
# 跳过 AI 分析，验证采集链路
python3 -m src.main inspect --skip-llm --no-notify
# 正常输出：报告已写入 reports/xxxx.md
```

### 5.6 启动 Web 界面

```bash
# 前台运行（测试）
python3 -m src.main web

# 访问 http://服务器IP:8000
```

## 6. 配置 systemd 开机自启（Web 模式）

```bash
sudo tee /etc/systemd/system/gdb-inspect.service << EOF
[Unit]
Description=三思GDB巡检平台 Web 服务
After=network.target

[Service]
Type=simple
User=$(whoami)
WorkingDirectory=$(pwd)
Environment="ANTHROPIC_API_KEY=sk-ant-xxxx"
ExecStart=$(pwd)/.venv/bin/python -m src.main web
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable gdb-inspect
sudo systemctl start gdb-inspect

# 查看状态
sudo systemctl status gdb-inspect
```

## 7. 防火墙配置

信创系统通常使用 `firewalld`：

```bash
# 开放巡检平台 Web 端口
sudo firewall-cmd --permanent --add-port=8000/tcp

# 开放 Prometheus（如需外部访问）
sudo firewall-cmd --permanent --add-port=9090/tcp

# 开放 ES（如需外部访问）
sudo firewall-cmd --permanent --add-port=9200/tcp

sudo firewall-cmd --reload
```

## 9. 常见安装问题

| 问题 | 原因 | 解决 |
|---|---|---|
| `pip install` 超时 | 网络问题 | 使用 `-i https://mirrors.aliyun.com/pypi/simple/` |
| ES 启动失败 `max_map_count` | 系统参数不足 | `sysctl -w vm.max_map_count=262144` |
| Prometheus 无数据 | scrape_config 未配置 Target | 编辑 `/etc/prometheus/prometheus.yml`，添加 Node Exporter 地址 |
| 端口被占用 | 其他进程占用 | `ss -tlnp \| grep 9090`，停止冲突进程 |
| Python 版本不足 | 系统内置 3.6/3.8 | 参见麒麟系统部署手册第 3 节升级 Python |
