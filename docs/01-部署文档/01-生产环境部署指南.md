# 生产环境部署指南

> 本指南面向运维工程师，介绍如何在生产环境部署X项目监控系统

---

## 1. 服务器准备

### 1.1 硬件要求

| 组件 | CPU | 内存 | 磁盘 | 网络 |
|------|-----|------|------|------|
| Prometheus | 2核 | 4GB | 50GB | 100Mbps |
| Elasticsearch | 2核 | 4GB | 100GB | 100Mbps |
| Grafana | 1核 | 1GB | 10GB | 100Mbps |
| 巡检程序 | 1核 | 1GB | 10GB | 100Mbps |

### 1.2 操作系统

- ✅ Ubuntu 20.04+
- ✅ CentOS 7+
- ✅ 麒麟V10（鲲鹏/飞腾）
- ✅ Windows Server 2019+

### 1.3 安装Docker

```bash
# Ubuntu/CentOS
curl -fsSL https://get.docker.com | sh
systemctl enable docker
systemctl start docker

# 麒麟系统
# 参考官方文档安装Docker
```

## 2. 网络规划

### 2.1 端口分配

| 服务 | 端口 | 用途 |
|------|------|------|
| Prometheus | 9090 | 指标存储 |
| Elasticsearch | 9200 | 日志存储 |
| Grafana | 3000 | 可视化 |
| 巡检Web | 8000 | Web管理 |
| Alertmanager | 9093 | 告警 |

### 2.2 防火墙配置

```bash
# Ubuntu
firewall-cmd --permanent --add-port=9090/tcp
firewall-cmd --permanent --add-port=9200/tcp
firewall-cmd --permanent --add-port=3000/tcp
firewall-cmd --permanent --add-port=8000/tcp
firewall-cmd --reload
```

## 3. 部署步骤

### 3.1 下载项目

```bash
git clone https://github.com/liuliu4356/kzx.git
cd kzx
```

### 3.2 修改配置

编辑 `config.yaml`:

```yaml
prometheus:
  url: http://实际IP:9090  # 改为服务器实际IP

elasticsearch:
  url: http://实际IP:9200  # 改为服务器实际IP
  username_env: ES_USERNAME
  password_env: ES_PASSWORD
```

### 3.3 数据持久化

编辑 `docker-compose.yml` 添加卷挂载:

```yaml
services:
  prometheus:
    volumes:
      - ./prometheus-data:/prometheus
      - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml

  elasticsearch:
    volumes:
      - ./es-data:/usr/share/elasticsearch/data
```

### 3.4 启动服务

```bash
docker-compose up -d

# 检查状态
docker-compose ps
```

### 3.5 验证部署

```bash
# 访问各服务
curl http://localhost:9090/-/healthy
curl http://localhost:9200
curl http://localhost:3000
curl http://localhost:8000
```

## 4. 安全加固

### 4.1 配置HTTPS

使用Nginx反向代理:

```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://localhost:8000;
    }
}
```

### 4.2 用户权限

```bash
# 创建专用用户
useradd -m -s /bin/bash xmonitor
chown -R xmonitor:xmonitor /opt/kzx
```

### 4.3 定期备份

```bash
# 备份配置
tar czf backup-config-$(date +%Y%m%d).tar.gz config.yaml prometheus/ grafana/

# 备份数据
docker exec elasticsearch tar czf /backup/es-data.tar.gz /usr/share/elasticsearch/data
```

## 5. 监控与告警

### 5.1 配置告警通知

编辑 `config.yaml`:

```yaml
notifiers:
  - type: dingtalk
    webhook_url: https://oapi.dingtalk.com/robot/send?access_token=xxx

  - type: email
    smtp_host: smtp.example.com
    smtp_port: 587
    from: monitor@example.com
    to: admin@example.com
```

### 5.2 设置定时任务

```bash
# Linux crontab
crontab -e

# 每天凌晨2点运行巡检
0 2 * * * /usr/bin/python3 /opt/kzx/venv/bin/python -m src.main inspect --skip-llm >> /var/log/inspect.log 2>&1
```

## 6. 常见问题

### 6.1 服务无法启动

```bash
# 检查日志
docker-compose logs prometheus
docker logs elasticsearch

# 检查端口占用
netstat -tlnp | grep 9090
```

### 6.2 指标采集失败

```bash
# 检查Prometheus Targets状态
curl http://localhost:9090/api/v1/targets

# 检查网络连通性
docker exec prometheus ping node-exporter
```

### 6.3 性能问题

```bash
# 检查资源使用
docker stats

# 清理旧数据
docker exec prometheus promtool tsdb delete 2024-01-01
```

### 7.1 版本升级

```bash
# 拉取最新代码
git pull origin master

# 重新构建
docker-compose build

# 重启服务
docker-compose down
docker-compose up -d
```

```bash
# 清理30天前的ES索引
curl -X DELETE "http://localhost:9200/logstash-2024.01.*"
```
