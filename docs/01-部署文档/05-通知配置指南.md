# 通知配置文档

本文档介绍三思GDB巡检平台的通知渠道配置方法。

## 支持的通知渠道

| 渠道 | 配置项 | 说明 |
|------|--------|------|
| 邮件 | SMTP服务器、端口、发件人、收件人等 | 系统通知 |
| 钉钉 | Webhook URL | 群机器人 webhook |
| 企业微信 | Webhook URL | 企业微信机器人 |
| 飞书 | Webhook URL | 飞书机器人 webhook |

## 配置位置

进入 **系统设置 → 通知** 页面进行配置。

## 各渠道配置详解

### 1. 邮件通知

需要配置以下 SMTP 参数：

- SMTP 服务器地址（如：smtp.qq.com）
- SMTP 端口（一般 465 或 587）
- 发件人邮箱地址
- 发件人密码或授权码
- 收件人邮箱地址（多个用逗号分隔）

### 2. 钉钉通知

1. 在钉钉群设置中添加机器人
2. 选择"自定义"机器人
3. 获取 Webhook 地址
4. 在通知配置页面填入 Webhook URL
5. 可设置加签密钥（可选）

### 3. 企业微信通知

1. 在企业微信群添加机器人
2. 获取 Webhook 地址
3. 填入配置页面

### 4. 飞书通知

1. 在飞书群添加自定义机器人
2. 获取 Webhook 地址
3. 填入配置页面

## 测试通知

配置完成后，可以点击"测试通知"按钮验证配置是否正确。

## 告警规则

在巡检过程中发现异常时，系统会自动发送通知到已配置的通知渠道。

可以配置：
- 通知级别（严重/警告/信息）
- 是否启用该渠道
- 通知接收时间段

## 常见问题

**Q: 收不到通知？**
A: 检查配置是否正确保存，测试通知是否成功

**Q: 钉钉提示签名不匹配？**
A: 检查加签密钥是否正确配置

**Q: 如何只发送严重告警？**
A: 在通知设置中设置只接收严重级别告警
