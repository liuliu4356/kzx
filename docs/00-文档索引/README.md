## 快速开始

**Docker 环境（推荐）：**
```bash
git clone https://github.com/liuliu4356/kzx.git
cd kzx
cp config.example.yaml config.yaml
# 修改 config.yaml 中的 Prometheus/ES 地址
python3 -m src.main web
# 浏览器访问 http://localhost:8000
```

**物理机环境（无 Docker）：**
参考《物理机安装指南》或《麒麟系统本地部署与实战使用手册》。

**首次使用？** 请先阅读《小白操作手册》。
