# 常见问题解答 (FAQ)

> 收集X项目使用过程中常见问题及解决方案

---

## 1. 安装与启动

### Q1: Docker启动失败，提示"WSL 2 installation is required"

**解决方法：**
1. 打开Windows更新，安装所有更新
2. 重启电脑
3. 再次尝试启动Docker

---

### Q2: 端口被占用，启动失败

**解决方法：**
```cmd
netstat -ano | findstr "9090"
taskkill /PID 进程ID /F
```

---

### Q3: docker-compose up -d 报错

**可能原因：**
- Docker未启动
- 配置文件格式错误

**解决方法：**
```bash
# 检查Docker状态
docker info

# 验证配置文件
docker-compose config
```

---

## 2. Prometheus问题

### Q4: 无法采集到指标

**排查步骤：**
1. 访问 http://localhost:9090
2. 点击 "Status" -> "Targets"
3. 检查是否有红色DOWN的Target

**解决方法：**
- 检查被监控服务器网络是否连通
- 确认Node Exporter是否运行

---

### Q5: 指标查询返回空

**可能原因：**
- 指标名称错误
- 时间范围不正确

**解决方法：**
```promql
# 尝试基础查询
up
node_load1
node_memory_MemAvailable_bytes
```

---

## 3. Elasticsearch问题

### Q6: 日志查询失败

**排查步骤：**
```bash
# 检查ES状态
curl http://localhost:9200

# 检查索引
curl http://localhost:9200/_cat/indices
```

---

### Q7: 巡检报告中ES部分无数据

**可能原因：**
- 索引名称不匹配（logstash-*）
- 日志缺少@timestamp字段

**解决方法：**
确保日志有@timestamp字段：
```json
{"@timestamp": "2026-05-02T10:00:00Z", "level": "ERROR", "message": "test"}
```

---

## 4. 巡检程序问题

### Q8: 运行巡检报错"ModuleNotFoundError"

**解决方法：**
```bash
pip install -r requirements.txt
```

---

### Q9: 报告生成失败

**排查：**
- 检查reports目录权限
- 检查config.yaml格式

---

### Q10: 巡检结果与预期不符

**可能原因：**
- 阈值设置不当
- 指标计算公式问题

**解决方法：**
调整config.yaml中的threshold值

---

## 5. Web界面问题

### Q11: Web界面返回500错误

**排查：**
```bash
docker logs x-web
```

**常见原因：**
- 配置文件缺失
- 模板渲染错误
- 缺少依赖

---

### Q12: 开始巡检按钮无响应

**可能原因：**
- API调用失败
- 巡检程序报错

**解决方法：**
1. 检查 /api/inspect 接口
2. 查看Web服务日志

---

## 6. 网络问题

### Q13: 容器间无法通信

**解决方法：**
```bash
# 检查网络
docker network ls

# 重新创建网络
docker network create kzx_x_default
```

---

### Q14: 无法从宿主机访问服务

**检查：**
- 端口映射是否正确
- 防火墙是否阻止

---

## 7. 性能问题

### Q15: Prometheus存储空间不足

**解决方法：**
```bash
# 清理旧数据
docker exec prometheus promtool tsdb delete 2024-01-01
```

---

### Q16: Elasticsearch查询慢

**优化：**
- 增加分片数量
- 定期清理旧索引

---

## 8. Web界面新增功能问题

### Q17: 巡检指标编辑按钮无反应

**问题描述：**
点击"编辑"按钮没有反应，弹窗不打开

**可能原因：**
- tojson过滤器未定义
- 自定义Jinja2环境缺少内置过滤器

**解决方法：**
1. 使用data属性方式替代tojson
2. 在按钮中添加所有字段的data属性
3. 通过editFromAttr函数从属性中读取数据

---

### Q18: 下载HTML报告提示"Not Found"

**问题描述：**
点击"下载"按钮返回 {"detail":"Not Found"}

**可能原因：**
- 服务未重启，新代码未生效
- 路由冲突或路径问题

**解决方法：**
1. 重启Web服务器使代码生效
2. 检查reports目录中文件是否存在
3. 确保download路由在正确位置
