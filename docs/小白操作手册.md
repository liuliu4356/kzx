# 三思GDB巡检平台 - 使用手册

> 本项目为 GoldenDB 数据库分布式集群的自动巡检工具，覆盖指标采集 → AI 分析 → 报告生成 → 告警通知全链路。

---

## 快速开始

### 1. 安装部署

```bash
# 克隆项目
git clone https://github.com/liuliu4356/kzx.git
cd kzx

# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt

# 初始化配置
cp config.example.yaml config.yaml
# 编辑 config.yaml 配置数据源
```

### 2. 启动Web服务

```bash
python -m src.main web --host 0.0.0.0 --port 8000
```

访问 http://localhost:8000

## 功能说明

### 首页
- 显示最近巡检报告
- 快速执行巡检
- 查看服务状态

### 机房管理 (/sites)
- 配置多机房Prometheus和ES数据源
- 支持编辑/复制/删除机房

### 巡检指标 (/queries)
- 配置Prometheus采集指标
- 配置ES日志查询
- 支持备份和恢复配置

### 系统设置 (/settings)
- **数据源连接**：配置数据源
- **AI分析**：配置大模型
- **通知**：配置告警通知
- **系统日志**：查看运行日志

### 通知配置
- **邮件通知**：SMTP配置
- **钉钉通知**：Webhook
- **企业微信**：Webhook
- **飞书通知**：Webhook
- 配置文档：/overview/notify

### 定时任务 (/cron)
- 配置自动巡检计划

### 巡检报告 (/reports)
- 查看历史报告
- 下载导出

## 常见问题

### Q: 如何添加新的监控指标？
A: 在巡检指标页面点击「+ 添加指标」，填写PromQL即可。

### Q: 如何配置告警通知？
A: 进入系统设置 → 通知，配置对应渠道，参考 /overview/notify。

### Q: 如何备份配置？
A: 巡检指标页面有「📦 备份」按钮，可创建配置备份。
