📧 邮件通知配置

如 smtp.qq.com、smtp.163.com

465（SSL）或 25

your_email@qq.com

多个用逗号分隔，如：test@example.com,admin@example.com

提示：QQ邮箱需开启IMAP/SMTP，获取授权码作为密码

💬 钉钉通知配置

  1. 打开电脑版钉钉 → 进入群设置 → 智能群助手
  2. 点击「添加机器人」→ 选择「自定义」
  3. 设置机器人名称 → 添加 → 复制Webhook地址
  4. 格式：https://oapi.dingtalk.com/robot/send?access_token=xxx

💬 企业微信通知配置

  1. 打开企业微信 → 进入群设置 → 群机器人
  2. 点击「添加机器人」→ 设置名称
  3. 复制Webhook地址
  4. 格式：https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx

🚀 飞书通知配置

  1. 打开飞书 → 进入群设置 → 群机器人
  2. 点击「添加机器人」→ 选择「自定义」
  3. 设置名称 → 复制Webhook地址
  4. 格式：https://open.feishu.cn/open-apis/bot/v2/hook/xxx

🔗 获取Webhook后的配置步骤

  1. 进入系统设置 → 通知
  2. 找到对应的通知渠道（钉钉/企业微信/飞书）
  3. 启用开关
  4. 粘贴Webhook URL
  5. 点击保存
  6. 点击「测试通知」验证配置
