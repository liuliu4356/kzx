# Git Workflow Skills

此技能帮助管理 Git 工作流。

## 安装方法

在 Claude Code 中运行：
```
/plugin install git-workflow@anthropic-agent-skills
```

## 功能

- 自动生成规范的 commit message
- 分支创建与管理
- 合并请求 (PR) 处理
- 冲突检测与解决
