# Code Review Skills

此技能用于自动代码审查。

## 安装方法

在 Claude Code 中运行：
```
/plugin install code-review@claude-plugins-official
```

## 功能

- 代码质量检查
- 安全漏洞扫描
- 性能优化建议
- 代码规范检查
