# Document Skills

此技能用于处理各种文档格式。

## 安装方法

在 Claude Code 中运行：
```
/plugin install document-skills@anthropic-agent-skills
```

## 功能

- PDF 文档解析
- Word (DOCX) 文档处理
- Excel (XLSX) 表格处理
- PowerPoint (PPTX) 演示文稿处理
